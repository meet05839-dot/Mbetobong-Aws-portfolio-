Project 1: Static Website Hosting on Amazon S3

Project Overview

This project demonstrates how to host a static website using Amazon Simple Storage Service (S3).

Objectives

* Understand Amazon S3.
* Create and configure an S3 bucket.
* Upload website files.
* Configure static website hosting.
* Test website accessibility.

AWS Services Used

* Amazon S3

Architecture

User → Internet → Amazon S3 → Static Website

Implementation Steps

1. Create an S3 bucket.
2. Upload HTML and CSS files.
3. Configure static website hosting.
4. Configure appropriate access permissions.
5. Test the website.

Skills Gained

* AWS storage management.
* Static website hosting.
* Basic HTML.
* AWS access permissions.
